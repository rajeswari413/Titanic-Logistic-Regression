# Titanic-Logistic-Regression
# Titanic Survival Prediction using Logistic Regression

## Project Description
This project uses Logistic Regression to predict whether a passenger survived the Titanic disaster.

## Features Used
- Pclass
- Sex
- Age
- Fare

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Model
Logistic Regression

## Result
The model achieved approximately 80.45% accuracy on the test data.

## Evaluation
The model was evaluated using:
- Accuracy
- Confusion Matrix
- Classification Report
